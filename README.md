# Wave

Wave is a clean rebuild of a personal second brain for saving material, finding it later, and grouping related items. This directory is currently in **Phase 0: repository foundation**. No application code has been added yet.

## Project documents

- [Progress.md](Progress.md) records what has actually been done and the next checkpoint.
- [Architecture Design.md](Architecture%20Design.md) records proposed design and open decisions.
- [Build Plan.md](Build%20Plan.md) describes the phase order.
- [AGENTS.md](AGENTS.md) gives working guidance for coding agents.

The previous prototype in a different directory is not part of this rebuild. See [Progress.md](Progress.md) before starting a new phase.
